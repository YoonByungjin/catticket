## 文字コードと形

- 文字コード: 4つとも **CP949**（BOM なし）。Java の名前は `MS949`（`application.yml` の `catticket.subway.charset`）。
- 改行は CRLF（ただし引用符の中の改行は LF だけ）。git が改行を変えないよう、`backend/.gitattributes` で `-text` にしている。区切りはカンマで、1行目が見出し。カンマを含む値は `"` で囲む（例: `"2,3번 출입구 복도 사이"`、`"교대(법원, 검찰청)"`）。
- 列は見出しの名前で取る（順番に頼らない）。

- 駅名の多言語表記の名前のない8列目は、ふつうは空。ただし2行（연번 96 `당고개`、259 `암사역사공원`）は、8列目に `"` で囲んだ注記（`※진접선 …`、`※별내선 …`）があり、**値の中に改行を含む**（1行が2〜3行にまたがる。ファイルの行数は 293 行だが、行としては 290）。
- 駅名の多言語表記の `일본어` には、CP949 にない文字が `?` に置き換わった値がある（05 の 4.2）。

### 문자 코드와 형식

- 문자 코드: 4개 모두 **CP949**(BOM 없음). Java 이름은 `MS949`(`application.yml`의 `catticket.subway.charset`).
- 줄바꿈은 CRLF(단 따옴표 안의 줄바꿈은 LF만). git이 줄바꿈을 바꾸지 않도록 `backend/.gitattributes`에서 `-text`로 했다. 구분자는 쉼표, 1행이 머리글. 쉼표를 포함한 값은 `"`로 감싼다(예: `"2,3번 출입구 복도 사이"`, `"교대(법원, 검찰청)"`).
- 열은 머리글 이름으로 가져온다(순서에 의존하지 않음).

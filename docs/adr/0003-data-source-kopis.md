# 0003. 公演データは KOPIS Open API から取得する

- 日付: 2026-10-30
- 状態: 提案（要件定義の後に判断する。サービス内容を作り直すため）

## 背景

初期版はチケットサイトをクローリングし、手作業で前処理して DB に入れた。そのため更新されず、2026年10月時点で全公演（444件）が終了済みだった。

## 決定

- 公演・会場データは **KOPIS（公演芸術統合電算網）Open API** から取得し、**毎日自動で更新**する。
- 対象はまずソウル（`signgucode=11`）のコンサート・ミュージカル。
- 展示は後回しにする（KOPIS に展示がなく、候補の公共 API は座標の有無が未確認）。
- コインロッカーのデータは更新頻度が低いため、初期版の CSV を一度だけ取り込む。

## 検討した選択肢

| 選択肢 | 判断 |
|---|---|
| クローリングの自動化 | サイト構造の変更で止まる。規約上の問題、サーバーの IP がブロックされる恐れ |
| **KOPIS Open API** | 公式の公開 API。会場の緯度・経度（`la`, `lo`）も取得できる |
| ソウル市 文化行事情報 | 詳細ページが「サービス終了」表示で、安定して使えるか不明 |
| 日本の公演データ | KOPIS に相当する公開 API が見つからない（自治体のイベント CSV は地域行事が中心） |

## 結果

- 良い点: 手作業がなくなり、常に最新のデータを表示できる。
- 注意点（API 仕様は `docs/kopis-api.md`）:
  - 1回の照会は最大31日・100件まで → 期間とページを分けて繰り返し呼ぶ。
  - 公演一覧 → 公演詳細 → 施設詳細の3段階で呼ばないと座標が取れない。
  - **http のみで認証キーが平文**で送られる → サーバー側からのみ呼ぶ。
  - 画面に出典の表示が必須。
  - 公演名・会場名は韓国語のみ。

## 한국어

> 상태: 제안 (서비스 내용을 다시 설계하므로 요건정의 후에 판단한다)

### 배경

첫 버전은 티켓 사이트를 크롤링하고 손으로 전처리해서 DB에 넣었다. 그래서 갱신되지 않았고, 2026년 10월 기준 모든 공연(444건)이 종료된 상태였다.

### 결정

- 공연·공연장 데이터는 **KOPIS(공연예술통합전산망) Open API**에서 가져오고, **매일 자동으로 갱신**한다.
- 대상은 우선 서울(`signgucode=11`)의 콘서트·뮤지컬.
- 전시는 뒤로 미룬다(KOPIS에 전시가 없고, 후보 공공 API는 좌표 제공 여부 미확인).
- 물품보관함 데이터는 자주 바뀌지 않으므로 첫 버전의 CSV를 한 번만 가져온다.

### 검토한 선택지

| 선택지 | 판단 |
|---|---|
| 크롤링 자동화 | 사이트 구조가 바뀌면 멈춤. 약관 문제, 서버 IP 차단 위험 |
| **KOPIS Open API** | 공식 공개 API. 공연장 위도·경도(`la`, `lo`)도 받을 수 있음 |
| 서울시 문화행사 정보 | 상세 페이지에 "서비스 종료"가 표시되어 안정적으로 쓸 수 있는지 불명 |
| 일본 공연 데이터 | KOPIS에 해당하는 공개 API를 찾지 못함 (지자체 이벤트 CSV는 지역 행사 위주) |

### 결과

- 좋은 점: 손작업이 없어지고 항상 최신 데이터를 보여줄 수 있다.
- 주의점(API 사양은 `docs/kopis-api.md`):
  - 한 번 조회는 최대 31일·100건 → 기간과 페이지를 나눠 반복 호출.
  - 공연 목록 → 공연 상세 → 시설 상세의 3단계로 불러야 좌표를 얻을 수 있다.
  - **http만 지원하고 인증키가 평문으로** 전송됨 → 서버에서만 호출.
  - 화면에 출처 표기 필수.
  - 공연명·공연장명은 한국어만 제공.

# 0004. 地図は Google Maps を使う

- 日付: 2026-10-30
- 状態: 提案（要件定義の後に判断する。サービス内容を作り直すため）

## 背景

初期版は Kakao Maps を使っていた。今回は日本語での画面表示を目標にしている。

## 決定

地図は **Google Maps JavaScript API** を使い、`language=ja` で日本語表示にする。Angular では公式の `@angular/google-maps` を使う。

## 検討した選択肢

| 選択肢 | 判断 |
|---|---|
| Kakao Maps | 韓国の地図データは詳しいが、日本語表示に対応していない |
| **Google Maps** | `language` パラメータで日本語表示。Angular 公式コンポーネントがある |

## 結果

Google の公式ドキュメント（2026-10-29 確認）:

- 韓国は地図表示（Map Tiles）とジオコーディングに対応。**経路案内（車・自転車・徒歩）と交通情報は非対応**。本サービスはマーカー表示だけなので影響なし。
- 料金: Dynamic Maps は月 10,000 回まで無料（以降 1,000 回あたり $7）。
- 注意点:
  - Google Cloud に請求先アカウント（カード）の登録が必要。
  - API キーはブラウザに出るため、HTTP リファラーと API の制限を必ずかける。
  - 地図上の地名は日本語になるが、KOPIS の公演名・会場名は韓国語のまま。

## 한국어

> 상태: 제안 (서비스 내용을 다시 설계하므로 요건정의 후에 판단한다)

### 배경

첫 버전은 Kakao Maps를 썼다. 이번에는 일본어 화면 표시를 목표로 한다.

### 결정

지도는 **Google Maps JavaScript API**를 쓰고 `language=ja`로 일본어로 표시한다. Angular에서는 공식 `@angular/google-maps`를 쓴다.

### 검토한 선택지

| 선택지 | 판단 |
|---|---|
| Kakao Maps | 한국 지도 데이터는 자세하지만 일본어 표시를 지원하지 않음 |
| **Google Maps** | `language` 파라미터로 일본어 표시. Angular 공식 컴포넌트가 있음 |

### 결과

Google 공식 문서 (2026-10-29 확인):

- 한국은 지도 표시(Map Tiles)와 지오코딩을 지원. **길찾기(자동차·자전거·도보)와 교통 정보는 미지원**. 이 서비스는 마커 표시만 하므로 영향 없음.
- 요금: Dynamic Maps는 월 10,000회까지 무료 (이후 1,000회당 $7).
- 주의점:
  - Google Cloud에 결제 계정(카드) 등록이 필요.
  - API 키가 브라우저에 노출되므로 HTTP 리퍼러와 API 제한을 반드시 건다.
  - 지도 위 지명은 일본어가 되지만 KOPIS의 공연명·공연장명은 한국어 그대로.

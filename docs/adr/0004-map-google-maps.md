# 0004. 地図は Google Maps を使う

- 日付: 2026-10-30
- 状態: 採用

## 背景

初期版は Kakao Maps を使っていた。今回は日本語での画面表示を目標にしている。

## 決定

地図は **Google Maps JavaScript API** を使い、`language=ja` で日本語表示にする。Angular では公式の `@angular/google-maps` を使う。

## 検討した選択肢

| 選択肢 | 判断 |
|---|---|
| Kakao Maps | 韓国の地図データは詳しいが、日本語表示に対応していない |
| **Google Maps** | `language` パラメータで日本語表示。Angular 公式コンポーネントがある |

## 結果

Google の公式ドキュメント（2026-10-29 確認）:

- 韓国は地図表示（Map Tiles）とジオコーディングに対応。**経路案内（車・自転車・徒歩）と交通情報は非対応**。本サービスはマーカー表示だけなので影響なし。
- 料金: Dynamic Maps は月 10,000 回まで無料（以降 1,000 回あたり $7）。
- 注意点:
  - Google Cloud に請求先アカウント（カード）の登録が必要。
  - API キーはブラウザに出るため、HTTP リファラーと API の制限を必ずかける。
  - 地図上の地名は日本語になるが、KOPIS の公演名・会場名は韓国語のまま。

# 0006. 地図は Google Maps JavaScript API を使い、使用量の上限と予算アラートを設定する

- 日付: 2026-11-05
- 状態: 採用（2026-11-05、人間が決定）
- 置き換え: **0004 を置き換える**（0004 の決定に、費用の上限・アラート、言語の切り替え、要件 F-05〜F-07 との関係を加える）。0004 の状態は「置き換え済み（→ 0006）」
- 関係する要件: F-01, F-05, F-06, F-07, F-10, N-07（U-14）

## 背景

- 要件定義で、地図に公演を印で表示する（F-01）、会場・現在地の周辺 500m の駅・コインロッカーを表示する（F-05〜F-07）、韓国語と日本語を切り替える（F-10）ことが決まった。
- 運用コストは月0円（U-12, N-07）。T-01 により、無料枠の中で使う条件でカードの登録を認めるが、**使用量の上限と予算アラートを必ず設定する**。
- 人間の希望は Google マップ（0004、提案）。0004 には費用の上限・アラートと、言語の切り替えの扱いが書かれていない。

## 決定

1. 地図は **Google Maps JavaScript API**（SKU: Dynamic Maps）を使う。Angular では公式の `@angular/google-maps` を使う（0004 と同じ）。
2. 地図の API は**地図の表示と印（マーカー）の表示だけ**に使う。
   - 500m 以内の判定（F-05〜F-07）は、会場・駅・現在地の座標からサーバー側で距離を計算する。Google の経路・距離の API は使わない（韓国では徒歩・車の経路が提供されていない）。
   - 現在地（F-07）はブラウザの位置情報の機能（Geolocation API）で取る。Google の API は使わない。
   - 住所から座標への変換（ジオコーディング）は使わない（会場の座標は KOPIS から取る。0008）。
3. 表示言語（F-10）: 地図の言語は API を読み込むときの `language` パラメータ（`ko` / `ja`）で決まる。言語を切り替えたときは、**ページを読み込み直して**新しい言語で地図を読み込む（読み込み直し1回につき地図の読み込みが1回増える）。具体的な画面の動きは画面設計（02）で決める。
4. **使用量の上限（T-01）**: Google Cloud コンソールの「割り当て（Quotas）」で、Maps JavaScript API の1日の地図の読み込み数の上限を **300 回/日** にする（無料枠 10,000 回/月 ÷ 31 日 ≒ 322 回。公式の手順どおり 31 で割り、余裕を持たせて少なくする）。
5. **予算アラート（T-01）**: 請求先アカウントに予算を作る。
   - 範囲: 請求先アカウント全体（すべてのプロジェクト・サービス）
   - 金額: 1 USD 相当（請求先アカウントの通貨で指定）
   - しきい値: 実際の費用の 1%・50%・100%（1% は約 0.01 USD で、最初の請求が出た時点で気づくため）
   - 通知先: 請求先アカウントの管理者（このプロジェクト専用の Google アカウント）のメール
6. **API キーの制限**: キーはブラウザに出るため、次の2つを必ず設定する。
   - アプリケーションの制限: HTTP リファラー（本番のドメイン（0010）と、開発用の `http://localhost:4200/*`）。本番用と開発用でキーを分ける。
   - API の制限: Maps JavaScript API だけ。
7. この Google Cloud プロジェクトは地図専用にする。reCAPTCHA は別の、課金を有効にしないプロジェクトに作る（0011）。

## 検討した選択肢

| 選択肢 | 日本語表示 | 費用・カード | 判断 |
|---|---|---|---|
| **Google Maps JavaScript API** | `language=ja` で地図の文字を日本語にできる | Dynamic Maps は月 10,000 回まで無料。以降 1,000 回あたり 7.00 USD。請求先アカウント（カード）が必要。割り当てで1日の上限をかけられる | **採用を提案。** 日本語表示ができ、上限を割り当てで強制できる |
| Kakao Maps | 日本語表示に対応していない（0004） | — | F-10・F-11 を満たせない |
| NAVER Maps（NAVER Cloud Platform） | 公式の仕様に「日本語」の記載はあるが、地図の文字を日本語で表示できる範囲は確認できなかった | 無料の利用量は代表アカウントだけに提供される（公式ガイド）。NAVER Cloud の登録（カード）が必要 | 日本語の地図表示を確認できないため採用しない |
| Leaflet + OpenStreetMap の標準タイル | 標準タイルで日本語の地名を表示できることは確認できなかった | 無料・カード不要。ただしタイルの利用ポリシーに「SLA や保証はない」「アクセスはいつでも取り消されうる」とある | 本番の公開 URL で使うには安定性の保証がない |

## 結果（良い点・注意点）

### 費用（月0円の範囲か）

| 項目 | 内容 |
|---|---|
| 無料枠 | Dynamic Maps: 月 10,000 回（地図の読み込みの成功1回 = 1回） |
| カード登録 | 必要（請求先アカウント） |
| 上限を超えたとき | 割り当て（300 回/日）を超えると、その日は地図の読み込みが失敗し、課金はされない。割り当てを設定しなかった場合は 1,000 回あたり 7.00 USD が請求される |
| 予算アラート | 請求先アカウント全体に 1 USD 相当の予算、1%・50%・100% で通知。**予算は使用量を止めない**（公式）ため、止めるのは割り当てで行う |
| 見積もり | 面談・学習用の公開で、利用者は少ない。1日 300 回（月約 9,300 回）は十分と見込む |

### 良い点

- 日本語・韓国語の地図表示ができ、Angular の公式コンポーネントがある。
- 割り当てで使用量を強制的に止められるので、請求が0円を超えない。

### 注意点

- 1日 300 回を超えると、その日の残りは地図が表示されない。地図が読み込めないときのエラー表示を画面設計（02）で決める。
- 言語の切り替えで読み込み直すと、読み込み回数が増える。
- 割り当てと請求のデータにはずれがあり、請求の表示は最大 48 時間遅れることがある（公式）。そのため上限は無料枠より少なくしている。
- 韓国の地図で、地名がどこまで日本語で表示されるかは実装のときに画面で確認する。
- 公演名・会場名は KOPIS の韓国語のままなので、翻訳は 0007 で行う。

## 한국어

### 0006. 지도는 Google Maps JavaScript API를 쓰고, 사용량 상한과 예산 알림을 설정한다

- 날짜: 2026-11-05
- 상태: 채택(2026-11-05, 사람이 결정)
- 대체: **0004를 대체한다**(0004의 결정에 비용 상한·알림, 언어 전환, 요건 F-05~F-07과의 관계를 더한다). 0004의 상태는 "대체됨(→ 0006)"
- 관련 요건: F-01, F-05, F-06, F-07, F-10, N-07 (U-14)

### 배경

- 요건정의에서 지도에 공연을 표시(F-01), 공연장·현재 위치 주변 500m의 역·보관함 표시(F-05~F-07), 한국어·일본어 전환(F-10)이 정해졌다.
- 운영 비용은 월 0원(U-12, N-07). T-01에 따라 무료 한도 안에서 쓰는 조건으로 카드 등록을 허용하지만, **사용량 상한과 예산 알림을 반드시 설정한다**.
- 사람의 희망은 Google 지도(0004, 제안). 0004에는 비용 상한·알림과 언어 전환 처리가 적혀 있지 않다.

### 결정

1. 지도는 **Google Maps JavaScript API**(SKU: Dynamic Maps)를 쓴다. Angular에서는 공식 `@angular/google-maps`를 쓴다(0004와 같음).
2. 지도 API는 **지도 표시와 마커 표시에만** 쓴다.
   - 500m 이내 판정(F-05~F-07)은 공연장·역·현재 위치 좌표로 서버에서 거리를 계산한다. Google의 경로·거리 API는 쓰지 않는다(한국에서는 도보·자동차 경로가 제공되지 않음).
   - 현재 위치(F-07)는 브라우저의 위치 정보 기능(Geolocation API)으로 얻는다. Google API는 쓰지 않는다.
   - 주소→좌표 변환(지오코딩)은 쓰지 않는다(공연장 좌표는 KOPIS에서 얻는다. 0008).
3. 표시 언어(F-10): 지도 언어는 API를 불러올 때의 `language` 파라미터(`ko` / `ja`)로 정해진다. 언어를 바꾸면 **페이지를 다시 불러와** 새 언어로 지도를 불러온다(다시 불러올 때마다 지도 로드가 1회 늘어난다). 구체적인 화면 동작은 화면 설계(02)에서 정한다.
4. **사용량 상한(T-01)**: Google Cloud 콘솔의 "할당량(Quotas)"에서 Maps JavaScript API의 하루 지도 로드 수 상한을 **300회/일**로 한다(무료 한도 10,000회/월 ÷ 31일 ≒ 322회. 공식 절차대로 31로 나누고 여유를 두어 줄임).
5. **예산 알림(T-01)**: 결제 계정에 예산을 만든다.
   - 범위: 결제 계정 전체(모든 프로젝트·서비스)
   - 금액: 1 USD 상당(결제 계정의 통화로 지정)
   - 기준: 실제 비용의 1%·50%·100% (1%는 약 0.01 USD로, 첫 청구가 생긴 시점에 알기 위해)
   - 알림 대상: 결제 계정 관리자(이 프로젝트 전용 Google 계정)의 메일
6. **API 키 제한**: 키가 브라우저에 노출되므로 다음 두 가지를 반드시 설정한다.
   - 애플리케이션 제한: HTTP 리퍼러(운영 도메인(0010)과 개발용 `http://localhost:4200/*`). 운영용과 개발용 키를 나눈다.
   - API 제한: Maps JavaScript API만.
7. 이 Google Cloud 프로젝트는 지도 전용으로 한다. reCAPTCHA는 결제를 켜지 않은 별도 프로젝트에 만든다(0011).

### 검토한 선택지

| 선택지 | 일본어 표시 | 비용·카드 | 판단 |
|---|---|---|---|
| **Google Maps JavaScript API** | `language=ja`로 지도 글자를 일본어로 표시 가능 | Dynamic Maps는 월 10,000회까지 무료. 이후 1,000회당 7.00 USD. 결제 계정(카드) 필요. 할당량으로 하루 상한을 걸 수 있음 | **채택 제안.** 일본어 표시가 되고 상한을 할당량으로 강제할 수 있다 |
| Kakao Maps | 일본어 표시 미지원(0004) | — | F-10·F-11을 충족하지 못함 |
| NAVER Maps(NAVER Cloud Platform) | 공식 사양에 "일본어" 기재는 있으나 지도 글자를 일본어로 표시할 수 있는 범위는 확인하지 못함 | 무료 이용량은 대표 계정에만 제공(공식 가이드). NAVER Cloud 가입(카드) 필요 | 일본어 지도 표시를 확인할 수 없어 채택하지 않음 |
| Leaflet + OpenStreetMap 표준 타일 | 표준 타일로 일본어 지명을 표시할 수 있는지 확인하지 못함 | 무료·카드 불필요. 단, 타일 이용 정책에 "SLA나 보증은 없다", "접근은 언제든 철회될 수 있다"고 되어 있음 | 운영 공개 URL에서 쓰기에는 안정성 보장이 없음 |

### 결과 (좋은 점·주의점)

#### 비용 (월 0원 범위인가)

| 항목 | 내용 |
|---|---|
| 무료 한도 | Dynamic Maps: 월 10,000회(지도 로드 성공 1번 = 1회) |
| 카드 등록 | 필요(결제 계정) |
| 한도를 넘었을 때 | 할당량(300회/일)을 넘으면 그날은 지도 로드가 실패하고 과금되지 않는다. 할당량을 설정하지 않으면 1,000회당 7.00 USD가 청구된다 |
| 예산 알림 | 결제 계정 전체에 1 USD 상당 예산, 1%·50%·100%에서 알림. **예산은 사용량을 멈추지 않으므로**(공식) 멈추는 것은 할당량으로 한다 |
| 추정 | 면접·학습용 공개로 이용자는 적다. 하루 300회(월 약 9,300회)면 충분하다고 본다 |

#### 좋은 점

- 일본어·한국어 지도 표시가 되고 Angular 공식 컴포넌트가 있다.
- 할당량으로 사용량을 강제로 멈출 수 있어 청구가 0원을 넘지 않는다.

#### 주의점

- 하루 300회를 넘으면 그날 남은 시간은 지도가 표시되지 않는다. 지도를 불러오지 못할 때의 오류 표시는 화면 설계(02)에서 정한다.
- 언어 전환으로 다시 불러오면 로드 횟수가 늘어난다.
- 할당량과 청구 데이터에는 차이가 있고, 청구 표시는 최대 48시간 늦을 수 있다(공식). 그래서 상한을 무료 한도보다 적게 했다.
- 한국 지도에서 지명이 어디까지 일본어로 표시되는지는 구현 때 화면에서 확인한다.
- 공연명·공연장명은 KOPIS의 한국어 그대로이므로 번역은 0007에서 한다.

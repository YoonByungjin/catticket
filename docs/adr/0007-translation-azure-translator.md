# 0007. 外部データの翻訳は Azure AI Translator の無料レベル（F0）を使う

- 日付: 2026-11-05
- 状態: 提案
- 関係する要件: F-02 ⑥, F-11, N-01, N-07（U-14, U-13）

## 背景

- 日本語表示のとき、画面に表示する外部データのテキストはすべて日本語に翻訳する（F-11 ①）。公演名・会場名・駅名は韓国語の原文を併記し（F-11 ②）、出演者名は翻訳するが原文は併記しない（F-11 ③）。ユーザーのレビューは翻訳しない（F-11 ④）。
- 日本語表示のキーワード検索は、原文と翻訳した公演名の両方を対象にする（F-02 ⑥）。そのため翻訳は**表示のたびではなく、収集のときに行って保存する**必要がある。
- 外部データは毎日収集する（F-08）。新しい・変わった公演の分だけ毎日翻訳が発生する。
- 月0円（U-12, N-07）。T-01 により、カード登録は認めるが、上限とアラートを必ず設定する。

## 決定

1. 翻訳 API は **Azure AI Translator（Text translation）の無料レベル F0** を使う（韓国語 `ko` → 日本語 `ja`）。
2. **収集のときに翻訳して保存する**（バッチの中で行う。05 で詳しく決める）。画面の表示のたびに API を呼ばない。
3. 翻訳の量を減らす。
   - **同じ原文は二度翻訳しない**（原文ごとに翻訳結果を保存して使い回す）。
   - 公演の項目が変わったときは、**変わった項目だけ**翻訳し直す。
   - ジャンル・公演の状態など、値の種類が決まっているものは API で翻訳せず、画面の文言と同じ方法（多言語の辞書）で訳す。
   - 駅名は、ソウル交通公社が公開している公式の日本語表記を使い、API で翻訳しない（0009）。
4. **使用量の上限（T-01）**
   - サービス側: F0 レベルは月 200 万文字までで、超えると `403001`（無料の割り当てを超えた）のエラーになり、課金されない。リソースは **F0 だけ**を作り、有料レベル（S1 など）は作らない。
   - アプリ側: 1か月の翻訳文字数を数え、**月 180 万文字**（F0 の 90%）に達したらその月は翻訳を止める。翻訳できなかったテキストは次の収集で再び翻訳する（そのあいだは韓国語の原文を表示する。表示の方法は 02 で決める）。
5. **予算アラート（T-01）**: Azure の Cost Management でサブスクリプションに月の予算を作る。金額 1 USD 相当、実際の費用の 1%・100% で、このプロジェクト専用のメールアドレスに通知する。
6. キー（サブスクリプションキー）はサーバーの環境変数（`.env`）にだけ置く。ブラウザから翻訳 API を呼ばない。
7. 呼び出しは REST API を Spring の HTTP クライアントで行う。Azure の SDK は入れない（新しいライブラリを増やさない）。

## 翻訳する文字数の見積もり

**仮定**（実装の最初の収集で実測し、この ADR の見積もりと比べる）:

| 項目 | 仮定 | 根拠 |
|---|---|---|
| 公演中・公演予定のソウルの公演 | 約 3,000 件 | 仮定（KOPIS の公開資料でソウルの件数を確認できなかったため、多めに置く） |
| 1件あたり翻訳する文字数 | 約 150 文字（公演名 20、出演者 40、チケット価格 30、公演時間の案内 40、上演時間・観覧年齢 20） | どの項目を表示するかは 02 で決まる。表示項目が増えたら見直す |
| 新しい・変わった公演 | 1日 約 100 件 | 仮定 |
| 会場名 | 約 1,000 か所 × 15 文字 | 初回だけ。以降は新しい会場の分だけ |
| コインロッカーの位置の文章 | 約 340 件 × 15 文字 | 四半期ごと、変わった文だけ（0009） |
| 駅名 | 0 文字 | 公式の日本語表記を使う（0009） |

**見積もり**:

| 時期 | 計算 | 文字数 |
|---|---|---|
| 初回の収集 | 3,000 × 150 + 1,000 × 15 + 340 × 15 | 約 47 万文字 |
| 毎日 | 100 × 150 | 約 1.5 万文字/日（月 約 45 万文字） |
| 最初の月の合計 | 47 万 + 45 万 | **約 92 万文字** |
| 2か月目以降 | — | **約 45 万文字/月** |

**無料枠との比較**:

| サービス | 無料枠（月） | 最初の月（約 92 万） | 2か月目以降（約 45 万） |
|---|---|---|---|
| **Azure AI Translator F0** | 200 万文字 | 46%。収まる | 23%。収まる |
| Google Cloud Translation | 50 万文字（Basic と Advanced で共通） | 超える | 90%。余裕がほとんどない |
| DeepL API Free | 50 万文字 | 超える | 90%。余裕がほとんどない |

見積もりが2倍にずれても（2か月目以降 約 90 万文字/月）、F0 の無料枠に収まる。

## 検討した選択肢

| 選択肢 | 無料枠 | カード | 上限を超えたとき | 判断 |
|---|---|---|---|---|
| **Azure AI Translator F0** | 月 200 万文字（1時間あたり 200 万文字まで） | Azure アカウントの登録で必要 | エラー `403001` で止まる。F0 は課金されない | **採用を提案。** 無料枠が最も大きく、超えても課金されない |
| Google Cloud Translation（Basic / Advanced の NMT） | 月 50 万文字（月 10 USD のクレジットとして適用） | 必要（請求先アカウント） | 超えた分は 100 万文字あたり 20 USD。割り当て（1日の文字数）を下げれば止められる | 見積もりでは無料枠に収まらない月がある。地図と同じ請求先にまとめられる点は良い |
| DeepL API Free | 月 50 万文字 | 本人確認のため必要（公式の文言は確認できなかった） | エラー `456`（割り当てを使い切った）で止まる | 無料枠が見積もりに足りない |
| 翻訳しない・人が訳す | — | — | — | F-11 ①（すべて翻訳）を満たせない |

## 結果（良い点・注意点）

### 費用（月0円の範囲か）

| 項目 | 内容 |
|---|---|
| 無料枠 | F0: 月 200 万文字（標準の翻訳とカスタム翻訳の学習の合計） |
| カード登録 | 必要（Azure アカウント） |
| 上限を超えたとき | F0 は `403001` のエラーで止まり、課金されない。アプリ側でも月 180 万文字で止める |
| 予算アラート | Cost Management の予算 1 USD 相当、1%・100% で通知。**予算は使用量を止めない**（公式）ため、止めるのは F0 の上限とアプリ側の上限で行う |

### 良い点

- 見積もりに対して無料枠に4倍以上の余裕がある。
- 上限を超えても課金されない（F0 だけを作る限り）。

### 注意点

- Azure の無料アカウントは、30日以内に従量課金（pay-as-you-go）へ移らないと無料サービスを使い続けられない（公式）。**従量課金のサブスクリプションには支出の上限（spending limit）を設定できない**（公式）。そのため、F0 以外の有料のリソースを作らないことと、予算アラートが重要になる。
- 地図（Google Cloud）とは別のクラウドのアカウント・カード登録が増える。
- 1回のリクエストは 5 万文字まで。初回の 47 万文字は分けて送る（1時間あたり 200 万文字の範囲で均等に送る）。
- 機械翻訳の固有名詞の品質は、原文の併記で補う（U-13 の決定。F-11 ②）。
- 見積もりの「仮定」が外れた場合（公演数が想定より多い、表示項目が増えた）、実測の値でこの ADR を見直す。

## 한국어

### 0007. 외부 데이터 번역은 Azure AI Translator 무료 등급(F0)을 쓴다

- 날짜: 2026-11-05
- 상태: 제안
- 관련 요건: F-02 ⑥, F-11, N-01, N-07 (U-14, U-13)

### 배경

- 일본어 표시일 때 화면에 보이는 외부 데이터 텍스트는 모두 일본어로 번역한다(F-11 ①). 공연명·공연장명·역명은 한국어 원문을 함께 적고(F-11 ②), 출연자명은 번역하되 원문은 함께 적지 않는다(F-11 ③). 사용자 리뷰는 번역하지 않는다(F-11 ④).
- 일본어 표시의 키워드 검색은 원문과 번역된 공연명 둘 다를 대상으로 한다(F-02 ⑥). 그래서 번역은 **표시할 때마다가 아니라 수집할 때 해서 저장**해야 한다.
- 외부 데이터는 매일 수집한다(F-08). 새로 생기거나 바뀐 공연만큼 매일 번역이 생긴다.
- 월 0원(U-12, N-07). T-01에 따라 카드 등록은 허용하지만 상한과 알림을 반드시 설정한다.

### 결정

1. 번역 API는 **Azure AI Translator(Text translation) 무료 등급 F0**을 쓴다(한국어 `ko` → 일본어 `ja`).
2. **수집할 때 번역해서 저장한다**(배치 안에서 한다. 05에서 자세히 정한다). 화면 표시 때마다 API를 부르지 않는다.
3. 번역량을 줄인다.
   - **같은 원문은 두 번 번역하지 않는다**(원문별로 번역 결과를 저장해 다시 쓴다).
   - 공연 항목이 바뀌면 **바뀐 항목만** 다시 번역한다.
   - 장르·공연 상태처럼 값의 종류가 정해진 것은 API로 번역하지 않고 화면 문구와 같은 방법(다국어 사전)으로 옮긴다.
   - 역명은 서울교통공사가 공개한 공식 일본어 표기를 쓰고 API로 번역하지 않는다(0009).
4. **사용량 상한(T-01)**
   - 서비스 쪽: F0 등급은 월 200만 자까지이고, 넘으면 `403001`(무료 할당 초과) 오류가 나며 과금되지 않는다. 리소스는 **F0만** 만들고 유료 등급(S1 등)은 만들지 않는다.
   - 앱 쪽: 한 달 번역 글자 수를 세어 **월 180만 자**(F0의 90%)에 이르면 그달은 번역을 멈춘다. 번역하지 못한 텍스트는 다음 수집 때 다시 번역한다(그동안은 한국어 원문을 보여준다. 표시 방법은 02에서 정한다).
5. **예산 알림(T-01)**: Azure Cost Management에서 구독에 월 예산을 만든다. 금액 1 USD 상당, 실제 비용의 1%·100%에서 이 프로젝트 전용 메일 주소로 알린다.
6. 키(구독 키)는 서버 환경변수(`.env`)에만 둔다. 브라우저에서 번역 API를 부르지 않는다.
7. 호출은 REST API를 Spring HTTP 클라이언트로 한다. Azure SDK는 넣지 않는다(새 라이브러리를 늘리지 않는다).

### 번역 글자 수 추정

**가정**(구현 첫 수집 때 실측해 이 ADR의 추정과 비교한다):

| 항목 | 가정 | 근거 |
|---|---|---|
| 공연 중·공연 예정인 서울 공연 | 약 3,000건 | 가정(KOPIS 공개 자료에서 서울 건수를 확인하지 못해 넉넉히 잡음) |
| 1건당 번역 글자 수 | 약 150자(공연명 20, 출연자 40, 티켓 가격 30, 공연 시간 안내 40, 상연 시간·관람 연령 20) | 어떤 항목을 표시할지는 02에서 정해진다. 표시 항목이 늘면 다시 본다 |
| 새로 생기거나 바뀐 공연 | 하루 약 100건 | 가정 |
| 공연장명 | 약 1,000곳 × 15자 | 처음만. 이후에는 새 공연장만 |
| 보관함 위치 설명 | 약 340건 × 15자 | 분기마다, 바뀐 글만(0009) |
| 역명 | 0자 | 공식 일본어 표기를 쓴다(0009) |

**추정**:

| 시기 | 계산 | 글자 수 |
|---|---|---|
| 첫 수집 | 3,000 × 150 + 1,000 × 15 + 340 × 15 | 약 47만 자 |
| 매일 | 100 × 150 | 약 1.5만 자/일 (월 약 45만 자) |
| 첫 달 합계 | 47만 + 45만 | **약 92만 자** |
| 둘째 달 이후 | — | **약 45만 자/월** |

**무료 한도와 비교**:

| 서비스 | 무료 한도(월) | 첫 달(약 92만) | 둘째 달 이후(약 45만) |
|---|---|---|---|
| **Azure AI Translator F0** | 200만 자 | 46%. 들어감 | 23%. 들어감 |
| Google Cloud Translation | 50만 자(Basic과 Advanced 공통) | 넘음 | 90%. 여유가 거의 없음 |
| DeepL API Free | 50만 자 | 넘음 | 90%. 여유가 거의 없음 |

추정이 2배로 어긋나도(둘째 달 이후 약 90만 자/월) F0 무료 한도 안에 들어간다.

### 검토한 선택지

| 선택지 | 무료 한도 | 카드 | 한도를 넘었을 때 | 판단 |
|---|---|---|---|---|
| **Azure AI Translator F0** | 월 200만 자(시간당 200만 자까지) | Azure 계정 가입에 필요 | 오류 `403001`로 멈춤. F0은 과금되지 않음 | **채택 제안.** 무료 한도가 가장 크고 넘어도 과금되지 않는다 |

### 결과 (좋은 점·주의점)

#### 비용 (월 0원 범위인가)

| 항목 | 내용 |
|---|---|
| 무료 한도 | F0: 월 200만 자(표준 번역과 커스텀 번역 학습의 합계) |
| 카드 등록 | 필요(Azure 계정) |
| 한도를 넘었을 때 | F0은 `403001` 오류로 멈추고 과금되지 않는다. 앱에서도 월 180만 자에서 멈춘다 |
| 예산 알림 | Cost Management 예산 1 USD 상당, 1%·100%에서 알림. **예산은 사용량을 멈추지 않으므로**(공식) 멈추는 것은 F0 상한과 앱 쪽 상한으로 한다 |

#### 좋은 점

- 추정에 비해 무료 한도에 4배 이상 여유가 있다.
- 한도를 넘어도 과금되지 않는다(F0만 만드는 한).

#### 주의점

- Azure 무료 계정은 30일 안에 종량제(pay-as-you-go)로 옮기지 않으면 무료 서비스를 계속 쓸 수 없다(공식). **종량제 구독에는 지출 한도(spending limit)를 설정할 수 없다**(공식). 그래서 F0 외의 유료 리소스를 만들지 않는 것과 예산 알림이 중요하다.
- 지도(Google Cloud)와 별도의 클라우드 계정·카드 등록이 늘어난다.
- 요청 1번은 5만 자까지. 첫 47만 자는 나눠서 보낸다(시간당 200만 자 범위에서 고르게 보낸다).
- 기계 번역의 고유명사 품질은 원문 병기로 보완한다(U-13 결정. F-11 ②).
- 추정의 "가정"이 빗나가면(공연 수가 예상보다 많음, 표시 항목이 늘어남) 실측값으로 이 ADR을 다시 본다.

# 0009. 駅・コインロッカーのデータは、ソウル交通公社の公開データから作る

- 日付: 2026-11-05
- 状態: 採用（2026-11-05、人間が決定）
- 関係する要件: F-05, F-06, F-07, F-11 ②, N-04（U-19, U-18, U-20, O-07）
- 0003 の「コインロッカーのデータは初期版の CSV を一度だけ取り込む」は、この ADR で扱う（0008 が 0003 を置き換える）

## 背景

- 会場・現在地から 500m 以内の、ソウル交通公社 1〜8号線のソウルにある駅（F-05, F-07）と、その駅のコインロッカー（F-06）を表示する。コインロッカーの位置は駅の座標と位置の文章で示す（U-20）。
- コインロッカーの候補は、人間が持っている `locker_lat_lng.csv`（U-16）。出典・基準日・ライセンスがファイルにない（企画書 8.）。
- `legacy` ブランチを確認した結果（2026-11-05）:
  - `django4/locker_lat_lng.csv` として公開済み。列は `보관함역, 위도, 경도, 주소, 상세위치`、316 行（見出しを除く）。
  - 出典・取得日・ライセンスは、ファイル・コード・`django4/docs/django-study.md` のどこにも書かれていない。データの取り込み方法もコードに残っていない（`import_concerts.py` は空のファイル）。
- 駅の位置データの出どころも決める必要がある（CSV にはコインロッカーのある駅しかない。U-18）。
- 駅名は日本語表示で翻訳し、原文を併記する（F-11 ②）。

## 決定

1. **`locker_lat_lng.csv` は本番のデータとして使わない。** 出典・ライセンスを確認できないため（U-19 で「確認できなければ別のデータを探す」とした）。
2. 代わりに、**ソウル交通公社が公共データポータル・ソウル열린데이터광장で公開している次のデータ**から作る。

| 用途 | データ | 提供 | 内容（公式ページの記載） | 基準日・更新 | 利用条件 |
|---|---|---|---|---|---|
| 駅の座標（F-05, F-06, F-07） | 서울교통공사_1_8호선 역사 좌표(위경도) 정보（data.go.kr 15099316） | 서울교통공사 토목처 | 1〜8号線の全 276 駅の緯度・経度（小数第6位）。列: 연번, 호선, 고유역번호(외부역코드), 역명, 위도, 경도, 작성일자, 작성기준일 | 修正日 2026-09-17。更新周期「年間」（新しい駅・移転・廃止のときに修正） | 이용허락범위 제한 없음 |
| 駅がソウルにあるかの判定（F-05 ②⑥） | 서울교통공사_역 주소 및 전화번호（data.go.kr 15044231・ファイル 15119348） | 서울교통공사 | 역번호, 호선, 역명, 전화번호, 도로명주소, 지번주소（1〜8号線と 9号線 2・3段階） | 2026年2月基準（検索結果のメタデータ） | 이용허락범위 제한 없음 |
| コインロッカーの位置の文章（F-06） | 서울교통공사_물품보관함 위치정보（data.go.kr 15044234） | 서울교통공사 사업계획처 | 列: 연번, 호선, 보관함명, 상세위치 | 2026-09-30（3분기）基準。登録・修正 2026-10-06。更新周期「分期」 | 이용허락범위 제한 없음 |
| 駅名の日本語（F-11 ②） | 서울교통공사_역명다국어표기（data.seoul.go.kr OA-2751） | 서울교통공사 수송운영처 | 1〜8号線の駅名の한글・漢字・英字・中国語・日本語表記 | 2024-09-27 基準。データ更新 2024-11-01 | 공공누리 제1유형（出典表示。商用・変更可） |

3. 作り方:
   - 駅: 座標のデータから 1〜8号線の駅を取り、住所のデータで**住所が「서울특별시」で始まる駅だけ**を残す（F-05 ⑥ のソウル外の駅を除く。X-24）。
   - コインロッカー: 位置情報のデータの「호선・보관함명」を駅の「호선・역명」に結びつけ、その駅の座標を使う（500m の判定も駅の座標。U-20）。結びつかない行は取り込まず、件数を記録して人が確認する。
   - 駅名の日本語: 多言語表記のデータの日本語表記を使う（機械翻訳しない。0007）。表記がない駅だけ機械翻訳する。
   - コインロッカーの位置の文章（例: 1번 출입구 주변）は機械翻訳する（0007）。
4. **更新の頻度（O-07 の提案）**: コインロッカーは提供元の更新に合わせて**四半期に1回**、駅（座標・住所・多言語表記）は**年に1回、または駅の開業・移転・廃止があったとき**に、人が最新のファイルを取得して取り込む。取り込みの手順・ファイルの置き場所はバッチ設計（05）と運用手順で決める。
5. 出典の表示: 公共ヌリ 제1유형のデータ（駅名の多言語表記）は出典の表示が必要。ほかの「제한 없음」のデータも、出典を画面に示す（場所は 02 で決める）。
6. `legacy` ブランチの CSV はそのままにする（`legacy` は変更しないルール）。

## 検討した選択肢

| 選択肢 | 判断 |
|---|---|
| `locker_lat_lng.csv` をそのまま使う | 出典・基準日・ライセンスを確認できない。列の構成は公式のコインロッカーのデータに近く、同じ系統のデータを加工したものと推定されるが、確かめられない。重複行・ソウル外の駅を含む |
| **ソウル交通公社の公式データを組み合わせる** | **採用を提案。** 出典・基準日・利用条件がページに示されている。駅とコインロッカーが同じ提供元で、1〜8号線の範囲（U-18）と一致する。四半期ごとに新しい版が出る |
| 国土交通部の鉄道駅の無人の便利施設（data.go.kr 15151815） | 全国の駅のデータで、範囲（ソウル交通公社 1〜8号線）の絞り込みが必要。駅の座標のデータとの結びつけも別に必要 |
| 地図 API で駅を探す（Places など） | 有料の SKU が増え、月0円の上限管理が難しくなる（0006 では地図の表示だけに使う） |

## 結果（良い点・注意点）

### 費用（月0円の範囲か）

| 項目 | 内容 |
|---|---|
| 無料枠 | 公開ファイルのダウンロードは無料（料金なし） |
| カード登録 | 不要 |
| 上限を超えたとき | 呼び出しの上限はない（ファイルを人が取得するため） |
| 上限・アラートの設定 | 課金がないため不要 |

### 良い点

- 出典・利用条件を説明できるデータだけを使う。
- 駅名の日本語が公式の表記になり、翻訳の文字数も減る。

### 注意点

- U-20（駅の座標 + 位置の文章で示す）は「CSV を使わないことになった場合は見直す」とされている。この ADR でも**示し方は同じ**（駅の座標 + 位置の文章）なので、要件の変更は不要と考える。人間に確認する。
- 「보관함명」が駅名と同じ書き方かどうかは、ファイルを取得して確かめる。結びつかない行が多い場合は、結びつけの規則をバッチ設計（05）で決める。
- 住所のデータは検索結果のメタデータで確認した。列の名前と基準日は、ファイルを取得したときに確かめる。
- 「이용허락범위 제한 없음」のデータには公共ヌリの類型の表示がない。公共データポータルの方針では、公共ヌリの類型ごとに出典表示の要否が決まる。安全のため出典を表示する。
- `legacy` ブランチに出典不明の CSV が公開されたまま残る。中身は公式の公開データと同じ系統と推定され、ルール上 `legacy` は変更できないため、そのままにする（削除が必要なら人間が判断する）。

## 한국어

### 0009. 역·물품보관함 데이터는 서울교통공사의 공개 데이터로 만든다

- 날짜: 2026-11-05
- 상태: 채택(2026-11-05, 사람이 결정)
- 관련 요건: F-05, F-06, F-07, F-11 ②, N-04 (U-19, U-18, U-20, O-07)
- 0003의 "물품보관함 데이터는 첫 버전의 CSV를 한 번만 가져온다"는 이 ADR에서 다룬다(0008이 0003을 대체한다)

### 배경

- 공연장·현재 위치에서 500m 안의, 서울교통공사 1~8호선 중 서울에 있는 역(F-05, F-07)과 그 역의 물품보관함(F-06)을 보여준다. 보관함 위치는 역 좌표와 위치 설명 글로 보여준다(U-20).
- 보관함 후보는 사람이 가진 `locker_lat_lng.csv`(U-16). 출처·기준일·라이선스가 파일에 없다(기획서 8.).
- `legacy` 브랜치를 확인한 결과(2026-11-05):
  - `django4/locker_lat_lng.csv`로 이미 공개되어 있다. 열은 `보관함역, 위도, 경도, 주소, 상세위치`, 316행(머리글 제외).
  - 출처·취득일·라이선스는 파일·코드·`django4/docs/django-study.md` 어디에도 없다. 데이터를 넣은 방법도 코드에 남아 있지 않다(`import_concerts.py`는 빈 파일).
- 역 위치 데이터의 출처도 정해야 한다(CSV에는 보관함이 있는 역만 있다. U-18).
- 역명은 일본어 표시에서 번역하고 원문을 함께 적는다(F-11 ②).

### 결정

1. **`locker_lat_lng.csv`는 운영 데이터로 쓰지 않는다.** 출처·라이선스를 확인할 수 없기 때문이다(U-19에서 "확인되지 않으면 다른 데이터를 찾는다"고 했다).
2. 대신 **서울교통공사가 공공데이터포털·서울열린데이터광장에 공개한 다음 데이터**로 만든다.

| 용도 | 데이터 | 제공 | 내용(공식 페이지 기재) | 기준일·갱신 | 이용 조건 |
|---|---|---|---|---|---|
| 역 좌표(F-05, F-06, F-07) | 서울교통공사_1_8호선 역사 좌표(위경도) 정보(data.go.kr 15099316) | 서울교통공사 토목처 | 1~8호선 전체 276개 역의 위도·경도(소수점 6자리). 열: 연번, 호선, 고유역번호(외부역코드), 역명, 위도, 경도, 작성일자, 작성기준일 | 수정일 2026-09-17. 갱신 주기 "연간"(신설·이전·폐쇄 때 수정) | 이용허락범위 제한 없음 |
| 역이 서울에 있는지 판정(F-05 ②⑥) | 서울교통공사_역 주소 및 전화번호(data.go.kr 15044231·파일 15119348) | 서울교통공사 | 역번호, 호선, 역명, 전화번호, 도로명주소, 지번주소(1~8호선과 9호선 2·3단계) | 2026년 2월 기준(검색 결과 메타데이터) | 이용허락범위 제한 없음 |
| 보관함 위치 설명(F-06) | 서울교통공사_물품보관함 위치정보(data.go.kr 15044234) | 서울교통공사 사업계획처 | 열: 연번, 호선, 보관함명, 상세위치 | 2026-09-30(3분기) 기준. 등록·수정 2026-10-06. 갱신 주기 "분기" | 이용허락범위 제한 없음 |
| 역명 일본어(F-11 ②) | 서울교통공사_역명다국어표기(data.seoul.go.kr OA-2751) | 서울교통공사 수송운영처 | 1~8호선 역명의 한글·한자·영자·중국어·일어 표기 | 2024-09-27 기준. 데이터 갱신 2024-11-01 | 공공누리 제1유형(출처 표시. 상업적 이용·변경 가능) |

3. 만드는 방법:
   - 역: 좌표 데이터에서 1~8호선 역을 가져오고, 주소 데이터로 **주소가 "서울특별시"로 시작하는 역만** 남긴다(F-05 ⑥의 서울 밖 역 제외. X-24).
   - 보관함: 위치정보 데이터의 "호선·보관함명"을 역의 "호선·역명"에 연결하고 그 역의 좌표를 쓴다(500m 판정도 역 좌표. U-20). 연결되지 않는 행은 넣지 않고 건수를 기록해 사람이 확인한다.
   - 역명 일본어: 다국어 표기 데이터의 일본어 표기를 쓴다(기계 번역하지 않음. 0007). 표기가 없는 역만 기계 번역한다.
   - 보관함 위치 설명(예: 1번 출입구 주변)은 기계 번역한다(0007).
4. **갱신 주기(O-07 제안)**: 보관함은 제공처 갱신에 맞춰 **분기에 1번**, 역(좌표·주소·다국어 표기)은 **1년에 1번, 또는 역 개통·이전·폐쇄가 있을 때** 사람이 최신 파일을 받아 넣는다. 넣는 절차·파일 위치는 배치 설계(05)와 운영 절차에서 정한다.
5. 출처 표시: 공공누리 제1유형 데이터(역명 다국어 표기)는 출처 표시가 필요하다. 다른 "제한 없음" 데이터도 화면에 출처를 보여준다(위치는 02에서 정함).
6. `legacy` 브랜치의 CSV는 그대로 둔다(`legacy`는 바꾸지 않는 규칙).

### 검토한 선택지

| 선택지 | 판단 |
|---|---|
| `locker_lat_lng.csv`를 그대로 쓴다 | 출처·기준일·라이선스를 확인할 수 없다. 열 구성이 공식 보관함 데이터와 비슷해 같은 계열 데이터를 가공한 것으로 추정되지만 확인할 수 없다. 중복 행·서울 밖 역이 섞여 있다 |
| **서울교통공사 공식 데이터를 조합한다** | **채택 제안.** 출처·기준일·이용 조건이 페이지에 나와 있다. 역과 보관함이 같은 제공처이고 1~8호선 범위(U-18)와 일치한다. 분기마다 새 판이 나온다 |
| 국토교통부 철도역 무인 편의시설(data.go.kr 15151815) | 전국 역 데이터라서 범위(서울교통공사 1~8호선)로 걸러야 한다. 역 좌표 데이터와의 연결도 따로 필요하다 |
| 지도 API로 역을 찾는다(Places 등) | 유료 SKU가 늘어 월 0원 상한 관리가 어려워진다(0006에서는 지도 표시에만 쓴다) |

### 결과 (좋은 점·주의점)

#### 비용 (월 0원 범위인가)

| 항목 | 내용 |
|---|---|
| 무료 한도 | 공개 파일 다운로드는 무료(요금 없음) |
| 카드 등록 | 불필요 |
| 한도를 넘었을 때 | 호출 상한이 없다(사람이 파일을 받기 때문) |
| 상한·알림 설정 | 과금이 없으므로 불필요 |

#### 좋은 점

- 출처·이용 조건을 설명할 수 있는 데이터만 쓴다.
- 역명 일본어가 공식 표기가 되고 번역 글자 수도 줄어든다.

#### 주의점

- U-20(역 좌표 + 위치 설명 글로 보여줌)은 "CSV를 쓰지 않게 되면 다시 검토한다"고 되어 있다. 이 ADR에서도 **보여주는 방식은 같으므로**(역 좌표 + 위치 설명 글) 요건 변경은 필요 없다고 본다. 사람에게 확인한다.
- "보관함명"이 역명과 같은 표기인지는 파일을 받아서 확인한다. 연결되지 않는 행이 많으면 연결 규칙을 배치 설계(05)에서 정한다.
- 주소 데이터는 검색 결과의 메타데이터로 확인했다. 열 이름과 기준일은 파일을 받을 때 확인한다.
- "이용허락범위 제한 없음" 데이터에는 공공누리 유형 표시가 없다. 공공데이터포털 방침에서는 공공누리 유형별로 출처 표시 여부가 정해진다. 안전하게 출처를 표시한다.
- `legacy` 브랜치에 출처 불명의 CSV가 공개된 채 남는다. 내용은 공식 공개 데이터와 같은 계열로 추정되고, 규칙상 `legacy`는 바꿀 수 없으므로 그대로 둔다(삭제가 필요하면 사람이 판단한다).

1. 목적·배경 — 기획서 요약과 이 시스템으로 실현할 것
2. 대상 사용자와 권한 — 사용자 종류 / 설명 / 할 수 있는 것
3. 기능 요건 — ID / 기능 / 우선순위(Must=첫 릴리스 필수, Should=가능하면, Could=여유 있으면) / 완료 기준(테스트로 확인 가능한 문장) / 비고. ID는 한 번 붙이면 바꾸지 않고, 그만둔 요건은 "폐지"로 남긴다.
   - 3.1 CRUD — 데이터별 목록·상세·등록·수정·삭제와 조작 가능한 사용자
4. 유스케이스 — 액터 / 조작 / 결과 / 요건 ID
5. 비기능 요건 — 지원 언어, 지원 단말·브라우저, 성능, 데이터 갱신, 보안, 가용성 (수치·구체적 조건으로)
6. 대상 외 — 이번에 만들지 않는 것
7. 미결 사항 — 질문 / 선택지 / 결정

## 한국어

구현의 기준(Single Source of Truth). 위에서부터 순서대로 정하고, 앞 단계가 바뀌면 뒤 설계서도 다시 검토한다.

| No. | 설계서 | 정하는 것 | 상태 |
|---|---|---|---|
| 01 | 요건정의서 | 누가·무엇을 위해 쓰는지, 기능 목록, 대상 외 | 작성 중 |
| 02 | 화면설계서 | 화면 목록, 각 화면의 요소와 동작 | 미착수 |
| 03 | API 설계서 | 엔드포인트, 요청·응답 | 미착수 |
| 04 | 테이블 설계서 | ER 다이어그램, 테이블 정의 | 미착수 |
| 05 | 배치 설계서 | KOPIS에서 정기 수집 | 미착수 |
